Refurbishing

Description
Refurbishing is a python project demonstrating how AI can assist with valuating and generating appropriate lisings for refurbished laptops. Accepting product specifications and a range of prices to compare, the average price is calculated via python to output the median. Along with this, it utilises LiteRouter to successfully generate a product listing.
